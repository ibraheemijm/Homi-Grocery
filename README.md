# Homi Grocery

**Homi Grocery** هو مشروع نظام إدارة بقالة احترافي لنظامي Linux/Windows وAndroid، بواجهة عربية RTL وتصميم Liquid Glass متوازن.

## حالة المشروع

بدأ التنفيذ البرمجي في مجلد `app/` باستخدام Flutter. النسخة الحالية هي **هيكل أولي للواجهة** وليست نظامًا محاسبيًا جاهزًا للاستخدام التجاري.

### ما تم بناؤه حتى الآن

- لوحة رئيسية عربية متجاوبة للكمبيوتر والهاتف.
- هوية بصرية أولية: الأخضر الداكن `#173D32`، الكريمي `#F7F4EA`، الذهبي `#C7A35A`، والأخضر الفاتح `#DCE9DF`.
- التبديل بين المظهر الفاتح والداكن.
- قائمة أقسام أولية وبطاقات ملخص واختصارات.
- اختبار واجهة أولي وفحوصات تلقائية عبر GitHub Actions.

## تشغيل نسخة Linux على Manjaro

من جذر المستودع:

```bash
cd app
flutter pub get
flutter doctor
flutter config --enable-linux-desktop
flutter run -d linux
```

إذا أظهر `flutter doctor` نقصًا في حزم Linux، ثبّت الحزم التي يذكرها فقط ثم أعد الأمر.

## الخطة التالية

1. تشغيل الواجهة والتحقق من نتائج التحليل والاختبارات.
2. تصميم قاعدة بيانات SQLite محلية ونماذج البيانات.
3. تنفيذ الأصناف ووحدات القياس والمخزون.
4. تنفيذ نقطة البيع والفواتير والتحصيلات ودفتر الديون مع اختبارات حسابية.
5. إضافة الموردين والمشتريات والخزينة والتقارير والطباعة.
6. إضافة النسخ الاحتياطي والصلاحيات وسجل التدقيق.
7. إعداد Android SDK وبناء نسخة Android.
8. تصميم خدمة مزامنة آمنة عند الحاجة إلى مشاركة البيانات بين الأجهزة.

لن تُعرض أي ميزة على أنها مكتملة قبل تنفيذها واختبارها عمليًا.
