# استيراد ملف ترخيص Homi

## رحلة العميل — التفعيل بالملفات فقط

- ينشئ العميل ملف `.hreq` داخل التطبيق ويرسله إلى إدارة Homi.
- ترفع الإدارة ملف الطلب من لوحة Homi Admin وتصدر `.hlic` بعد المراجعة وتأكيد الدفع.

## رحلة استيراد الترخيص

- من شاشة «تفعيل Homi Grocery» يختار العميل «استيراد ملف الترخيص (.hlic)».
- يحدد ملف الترخيص الذي أرسلته إدارة Homi عبر WhatsApp كملف Document.
- يقرأ التطبيق الملف محليًا ولا يحتاج إلى اتصال بالإنترنت لإتمام التحقق والاستيراد.
- لا يحفظ التطبيق الترخيص إلا بعد نجاح التحقق من توقيع Ed25519، ومعرّف المنتج، وسياسة الصلاحية، وبصمة المفتاح العام المحلي للجهاز.
- بعد نجاح الاستيراد ينتقل التطبيق إلى بوابة المصادقة المعتادة، دون تغيير قاعدة بيانات المتجر أو بيانات الدخول المحلية.

## تنسيق الملف

الملف JSON UTF-8 بامتداد .hlic، وبحد أقصى 128 KiB. يحتوي format وformat_version وstatus وlicense_id وdevice_id وkey_id وpayload وsignature. التوقيع يغطي بايتات payload الأصلية، وليس الغلاف الخارجي.

## ضوابط التنفيذ

- لا يطلب التطبيق بريدًا أو حسابًا أو كلمة مرور للمنصة.
- لا يحتوي الملف على أي مفتاح خاص.
- لا يُقبل ملف موقع بمفتاح غير موجود ضمن مفاتيح الثقة المضمّنة في التطبيق.
- لا يُقبل ملف لا يحتوي بصمة مفتاح الجهاز الحالي.
- لا يستبدل الترخيص الحالي ولا يمسح طلب التفعيل إلا بعد نجاح جميع الفحوص.
- يمسح التطبيق تصريح Offline Grant السابق بعد الاستيراد لمنع ربطه بترخيص مختلف.
- لا يُحذف أي ملف أو سجل من قاعدة بيانات المتجر بسبب الاستيراد أو رفض الملف.

راجع مستند Homi Platform MANUAL_LICENSE_FILE_FORMAT.md لمعرفة العقد الكامل للملف ومسار إصداره من لوحة الإدارة.
