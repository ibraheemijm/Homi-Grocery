# تكامل تفعيل Homi Grocery

## نطاق التغيير

هذا التكامل يخص التفعيل والاشتراك فقط. لا يغيّر قاعدة بيانات المبيعات أو المخزون أو الديون أو الموردين أو التقارير أو أي منطق تجاري داخل التطبيق.

## مسار التفعيل

1. يدخل المستخدم اسم العميل/المتجر ورقم الهاتف الدولي والخطة المطلوبة.
2. يمكن إرسال الطلب مباشرة عبر API، أو إنشاء ملف `.hreq` محليًا لرفعه لاحقًا من موقع Homi.
3. يثبت التطبيق ملكية الجهاز بتوقيع Ed25519؛ المفتاح الخاص يبقى في التخزين الآمن ولا يضاف إلى الملف.
4. تراجع الإدارة الطلب وإثبات الدفع اليدوي.
5. ينزّل العميل ملف `.hlic` بعد اعتماد الإدارة ويستورده داخل التطبيق.
6. يتحقق التطبيق محليًا من توقيع الترخيص ومفتاح الثقة وبصمة الجهاز.

## صيغة HREQ v1

الغلاف JSON:

```json
{
  "format": "HOMI_ACTIVATION_REQUEST",
  "format_version": 1,
  "payload": "BASE64URL_UTF8_JSON_PAYLOAD",
  "signature": "BASE64URL_ED25519_SIGNATURE"
}
```

التوقيع يغطي النص التالي حرفيًا:

```
HOMI_HREQ_V1
{SHA256_HEX_OF_EXACT_PAYLOAD_BYTES}
```

تتضمن الحمولة معرف الطلب والجهاز، وبيانات العميل والخطة المطلوبة، والمنصة والمعمارية والمفتاح العام وبصمته وإصدار التطبيق. لا تتضمن بريدًا إلكترونيًا أو كلمة مرور أو المفتاح الخاص أو بيانات المتجر التجارية.

## إعدادات البناء

- `HOMI_PLATFORM_BASE_URL`: عنوان Worker API (يجب أن يبدأ بـ HTTPS في الإنتاج).
- `HOMI_WEBSITE_BASE_URL`: عنوان الموقع، ويستخدم لفتح صفحة التفعيل.
- `HOMI_LICENSE_TRUSTED_PUBLIC_KEYS_B64`: مفاتيح التحقق العامة فقط.
- `HOMI_PLATFORM_ROOT_KEY_ID`: معرف مفتاح الجذر العام الذي يوقع keyset.
- `HOMI_PLATFORM_ROOT_PUBLIC_KEY`: المفتاح العام للجذر بصيغة Base64؛ ليس سرًا ولا يحتوي على المفتاح الخاص.
- `HOMI_APP_VERSION`: إصدار التطبيق الظاهر في ملف الطلب.
- `HOMI_BUILD_NUMBER`: رقم البناء الظاهر في ملف الطلب.

لا تضع مفتاح توقيع خاصًا أو أسرار المنصة في تطبيق Flutter أو GitHub. مفتاح إصدار التراخيص يبقى في Worker Secret.


## تحديثات التطبيق (OTA)

- يظهر فحص التحديث في إعدادات المدير على Android وWindows.
- يستخدم التطبيق نقطة التحديث العامة دون حساب عميل أو رمز وصول.
- يتحقق أولًا من keyset الموقع بمفتاح الجذر، ثم من توقيع manifest بمفتاح مخصص للتحديثات، ثم يطابق المنتج والمنصة والمعمارية والقناة ورقم البناء واسم الملف والحجم وبصمة SHA-256.
- لا يعرض التطبيق خيار التنزيل إلا بعد التحقق من manifest، ولا يعرض خيار التثبيت إلا بعد اكتمال التنزيل والتحقق من الحجم والبصمة.
- Android: يفتح مثبت Android الرسمي بعد موافقة المستخدم. إذا لم يكن إذن تثبيت التطبيقات من هذا المصدر مفعّلًا، يوجه المستخدم إلى إعدادات الإذن ثم يعود ليضغط التثبيت.
- Windows: يشغّل منسق التحديث المثبت بواسطة Inno Setup من مجلد ProgramData. يطلب UAC عند الحاجة، ويغلق التطبيق قبل تبديل الملفات، ثم يشغّل النسخة الجديدة ويتحقق من علامة صحة التشغيل؛ إذا فشل الفحص يطلب استرجاع النسخة السابقة.
- لا يوجد تثبيت صامت. لا يغيّر التحديث قاعدة بيانات المتجر أو مجلد بيانات Homi.
- حزمة Android المنشورة يجب أن تكون Universal APK ويكون architecture_key مساويًا universal. حزمة Windows تكون ZIP لمعمارية x64 وتحتوي ملفات مجلد Release مباشرة.
- يجب زيادة رقم البناء HOMI_BUILD_NUMBER مع كل إصدار منشور؛ فحص التحديث يقارن رقم البناء وليس الاسم الظاهر فقط.
- يلزم ضبط متغيرات GitHub Actions العامة HOMI_PLATFORM_BASE_URL وHOMI_PLATFORM_ROOT_KEY_ID وHOMI_PLATFORM_ROOT_PUBLIC_KEY قبل اختبار OTA الفعلي. لا تضع أي مفتاح خاص في GitHub Variables أو ملفات التطبيق؛ المفتاح الخاص يبقى في Worker Secret.

## الفترة التجريبية المحلية

- تبدأ التجربة عند أول دخول فعلي للمدير إلى مساحة العمل، وليس عند محاولة دخول الكاشير قبل إعداد المدير.
- مدتها 14 يومًا متصلة من وقت البدء المحفوظ في التخزين الآمن للجهاز.
- سجل التجربة المحلي ليس ملف ترخيص .hlic ولا توقيعًا صادرًا من الخادم؛ هو استحقاق محلي مربوط بهوية الجهاز، بينما تظل التراخيص المدفوعة موقعة ومتحققًا منها بمفتاح الثقة.
- تعمل دون اتصال بالإنترنت، ولا تحتاج إلى طلب ترخيص من الخادم لبدء العد.
- بعد انتهاء المدة يتحول التطبيق إلى القراءة والتصدير فقط، ولا تُحذف بيانات المتجر.
- يحتفظ التطبيق بآخر وقت استخدام لرصد إرجاع ساعة النظام إلى الوراء؛ عند اكتشاف تراجع زمني يوقف صلاحية العمل الكاملة بدل تمديد التجربة.
- لا يمكن ضمان منع إعادة التجربة بصورة مطلقة على جهاز يتحكم صاحبه في النظام أو يمسح بيانات التطبيق/التخزين الآمن. لذلك لا تدّعي المنظومة حماية مطلقة من إعادة التثبيت أو استعادة نسخة نظام قديمة.
- عند استيراد ترخيص مدفوع موقع، تكون له الأولوية على سجل التجربة المحلي، دون حذف سجل التجربة أو المساس بقاعدة بيانات المتجر.
