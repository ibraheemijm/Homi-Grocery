- اسم التطبيق: **Homi Grocery**.

- ترتيب المنصات: نسخة Linux على Manjaro أولًا، ثم Android، ثم Windows عبر GitHub Actions.
- الواجهة عربية RTL، مع دعم الثيم الفاتح/الداكن تلقائيًا، وتصميم Liquid Glass متوازن.
- الألوان: أخضر داكن `#173D32`، كريمي `#F7F4EA`، ذهبي `#C7A35A`، وأخضر فاتح `#DCE9DF`.

- السماح بالمخزون السالب مع تحذير واضح وتسجيله، بدل منع البيع.
- عدم دمج Pull Request قبل نجاح التحليل والاختبارات والبناء.
