# توزيع Windows وحماية بيانات المتجر

## هدف المرحلة

تجهيز مثبت Windows بصيغة EXE باستخدام Inno Setup، مع فصل ملفات البرنامج عن بيانات المتجر. هذه الخطوة تخص التثبيت والإزالة فقط، ولا تنفذ تحديث OTA داخل التطبيق.

## بناء المثبت

- يبني GitHub Actions تطبيق Flutter بوضع Release لمعمارية x64.
- يجمع Inno Setup ملفات مجلد Release في `Homi-Grocery-Setup-x64.exe`.
- يقرأ رقم الإصدار من `app/pubspec.yaml` بدل تكراره يدويًا في ملف المثبت.
- يثبت التطبيق افتراضيًا داخل Program Files بصلاحيات إدارية.
- ينشئ اختصار قائمة ابدأ، ويتيح اختصار سطح المكتب اختياريًا.
- يظل مجلد بيانات المستخدم خارج مجلد تثبيت البرنامج؛ لذلك لا يستهدفه إجراء إزالة التثبيت.

## بيانات المتجر

قاعدة SQLite وصور الأصناف والخطوط المستوردة والنسخ الاحتياطية ليست ملفات تثبيت. يحتفظ التطبيق بموقعها عبر خدمة AppDataLocation. لا يجوز للمثبت أو مزيل التثبيت حذف مجلد البيانات أو ملف إعداد الموقع.

ميزة نقل البيانات الحالية مخصصة لـ Windows وLinux، وتحتاج اختبارًا عمليًا قبل اعتمادها للاستخدام الفعلي. يوصى بقرص مادي مستقل للنسخ الاحتياطية؛ اختيار قسم آخر على القرص نفسه لا يحمي من تلف القرص بالكامل.

## حدود المثبت الحالي

- المثبت الحالي x64 فقط.
- لا يوجد توقيع رقمي للملف التنفيذي أو للمثبت بعد؛ قد يعرض Windows SmartScreen تحذيرًا.
- لا يوجد تحديث تلقائي أو آلية استبدال ملفات البرنامج أو rollback حتى الآن.
- المثبت لا ينشر Homi Platform API ولا يضبط عنوان الخادم أو مفاتيح توقيع التحديثات.
- لم يتم اختبار التثبيت والترقية والإزالة على جهاز Windows فعلي حتى الآن.

## اختبارات القبول المطلوبة

1. تثبيت نظيف على Windows 10/11 x64 وتشغيل التطبيق.
2. التأكد من إنشاء اختصارات قائمة ابدأ وسطح المكتب حسب اختيار المستخدم.
3. إدخال بيانات اختبار ثم إغلاق التطبيق.
4. تشغيل المثبت مرة أخرى فوق النسخة المثبتة والتحقق من عدم المساس ببيانات المتجر.
5. إزالة التطبيق والتحقق من بقاء مجلد بيانات المتجر وقاعدة SQLite.
6. إعادة التثبيت والتحقق من ظهور البيانات السابقة.
7. اختبار نقل البيانات إلى قسم آخر ثم إعادة تشغيل Windows والتحقق من فتح قاعدة البيانات الصحيحة.
8. اختبار فشل الوصول للقسم المحدد والتأكد من عدم إنشاء قاعدة بيانات فارغة بديلة.

لا تعتبر حزمة CI إصدارًا ميدانيًا مستقرًا قبل اجتياز هذه الاختبارات على جهاز Windows حقيقي.
