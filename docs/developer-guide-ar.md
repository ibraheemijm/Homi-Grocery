# دليل المطوّر — Homi Grocery

هذا الدليل يشرح طريقة تنظيم المشروع حتى يسهل توسيعه وصيانته مستقبلًا.

## قواعد كتابة الكود

1. **التعليقات باللغة العربية:** اشرح مسؤولية الملف أو الصنف أو الدالة، وسبب القرار عندما لا يكون واضحًا من الكود.
2. **الأسماء البرمجية واضحة:** تبقى أسماء الأصناف والمتغيرات والدوال بالإنجليزية وفق أسلوب Dart المعتاد، بينما تكون الشروحات للمطوّر بالعربية.
3. **لا تكرر منطق الأعمال داخل الواجهة:** الواجهة مسؤولة عن العرض والتفاعل، أما الحسابات المالية وقواعد المخزون فتُنقل إلى طبقة مستقلة.
4. **اختبر قبل اعتبار الميزة مكتملة:** أضف اختبارات للحالات الطبيعية والحالات الحدّية، خصوصًا المدفوعات والخصومات والرصيد والمخزون السالب.
5. **لا تدّعِ حفظ البيانات قبل تنفيذه:** أي شاشة أو رسالة عن التخزين أو المزامنة يجب أن تطابق ما يعمل فعليًا.
6. **التعديلات المالية لا تُحذف بصمت:** تُسجّل عمليات الإلغاء والتصحيح في سجل واضح بدل محو أثر العملية.
7. **استخدم مبالغ دقيقة:** عند تنفيذ الحسابات المالية، تجنب الاعتماد على الأعداد العشرية الثنائية مباشرة؛ اعتمد تمثيلًا دقيقًا مثل الوحدات النقدية الصحيحة، بعد تحديد قواعد التقريب.

## تنظيم المجلدات المستهدف

مع نمو التطبيق، ننقل الشيفرة من الملف الأولي `lib/main.dart` إلى وحدات واضحة:

- `lib/app/`: إعداد التطبيق والثيم والتنقل.
- `lib/core/`: أدوات مشتركة وتنسيق العملة والتحقق من المدخلات.
- `lib/data/`: قاعدة SQLite ومستودعات البيانات والترحيلات.
- `lib/features/products/`: الأصناف ووحدات القياس والمخزون.
- `lib/features/sales/`: نقطة البيع والفواتير والمدفوعات.
- `lib/features/customers/`: الزبائن والأرصدة والتحصيلات.
- `lib/features/purchases/`: الموردون والمشتريات.
- `lib/features/cashbox/`: الخزينة والمصروفات والورديات.
- `lib/features/reports/`: التقارير والطباعة.
- `test/`: اختبارات الواجهة والمنطق والحسابات.

هذا التنظيم هدف مرحلي؛ لا ننشئ ملفات فارغة لمجرد ملء المجلدات. تُضاف كل وحدة عندما يبدأ تنفيذ وظيفتها الفعلية.

## فحوصات الجودة

من داخل مجلد `app/`:

```bash
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter build linux
```

إذا فشل أي أمر، راجع السبب وأصلحه قبل إعلان نجاح البناء. بناء Linux لا يثبت وحده أن نسخة Android جاهزة؛ لكل منصة فحوصاتها الخاصة.
