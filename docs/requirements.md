# Homi Grocery

**نظام إدارة بقالة احترافي لنظامي Windows وAndroid**

Homi Grocery هو مشروع لنظام إدارة متكامل للبقالات والمتاجر الصغيرة، يهدف إلى تسهيل عمليات البيع وإدارة المخزون والديون والمشتريات والخزينة، من خلال واجهة عربية حديثة بتصميم Liquid Glass مستوحى من الواجهات الزجاجية المعاصرة.

## أهداف المشروع

- إنشاء واجهة عربية بالكامل تدعم اتجاه الكتابة من اليمين إلى اليسار (RTL).
- دعم Windows وAndroid بتجربة استخدام مناسبة لكل جهاز.
- توفير العمل دون اتصال بالإنترنت مع مزامنة البيانات عند عودة الاتصال.
- تبسيط عمليات البيع النقدي والآجل والمختلط.
- إدارة الأصناف والمخزون ووحدات القياس والتحويل بينها.
- إدارة الزبائن ودفتر الديون والتحصيلات.
- إدارة الموردين والمشتريات والمبالغ المستحقة.
- إدارة الخزينة والمصروفات والورديات.
- توفير التقارير المالية وتقارير المبيعات والمخزون.
- دعم الطباعة والنسخ الاحتياطي والاستعادة.
- تطبيق صلاحيات منفصلة للمدير والكاشير مع سجل تدقيق للعمليات المهمة.

### أسلوب الواجهات

- تأثير Liquid Glass متوازن.
- بطاقات شبه شفافة وحدود ناعمة وطبقات بصرية واضحة.
- دعم المظهر الفاتح والداكن والتبديل اليدوي.
- تصميم متجاوب ومناسب لشاشات الكمبيوتر والهواتف.
- خطوط عربية واضحة مثل Cairo أو IBM Plex Sans Arabic.
- الحفاظ على وضوح النصوص والأرقام المالية وقابلية الاستخدام أثناء البيع.

## التقنية المقترحة

- Flutter لتطوير واجهات مشتركة لنظامي Windows وAndroid.
- SQLite للتخزين المحلي والعمل دون إنترنت.
- خدمة مزامنة مركزية آمنة عند الحاجة إلى مشاركة البيانات بين الأجهزة.
- نظام نسخ احتياطي مشفر مع اختبار استعادة البيانات.
- اختبارات للتأكد من صحة العمليات المالية ومنع تكرار العمليات أثناء المزامنة.

هذه التقنيات مقترحة وليست إعلانًا عن اكتمال التنفيذ.

## تنظيم المستودع

- `design/` — تصميمات الواجهات والصور المرجعية.
- `docs/` — المتطلبات والمواصفات وقواعد الحسابات.
- `assets/` — الشعارات والأيقونات والموارد البصرية.
- `app/` — كود التطبيق عند بدء التنفيذ.
- `tests/` — حالات الاختبار ونتائجها.
